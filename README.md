# Tron P2P — projeto de Redes

Tron multijogador com lobby, sockets TCP e protocolo próprio de confirmação, eleição e recuperação.

**Comece por [docs/README.md](docs/README.md).** A documentação separa visão geral, implementação e consulta técnica.

Regra da retomada: três segundos de contagem; teclado liberado somente nos últimos 500 ms.

Os documentos descrevem o contrato a implementar. Os comandos de execução e as garantias devem ser verificados nos testes do aplicativo.
